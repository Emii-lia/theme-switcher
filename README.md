# Gnome theme switcher

This project contains two executables (command-line and gui) that switches theme on my CachyOS.
I needed it to smoothly switch between themes without doing tons of configurations

### Changes include:
- Wallpaper
- Icons
- Cursor
- Gtk-theme
- Shell theme
- Neofetch image
- Conky (fonts, colors, alignment, avatar)

Just for fun

P.S: This configuration is for **fish** ; you'll need to adapt the script if you use different shell.
